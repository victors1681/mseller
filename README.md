# MSeller React Native - eCommerce

MSeller is a **React Native** mobile app designed to offer a seamless eCommerce experience with full integration to **WooCommerce** using **GraphQL**.

📺 **Demo Video**  
Check out the app in action: [Watch on YouTube](https://youtube.com/shorts/aLK8OvMf4dM)

## 🔧 Features

- 🛒 eCommerce functionality powered by WooCommerce
- ⚛️ Built with React Native for cross-platform performance
- 🚀 GraphQL integration for efficient data fetching
- 📦 Product listing, detail view, cart, and order tracking
- 🔐 Authentication and secure checkout

## 📱 Tech Stack

- React Native
- GraphQL
- WooCommerce REST API & custom GraphQL layer
- Apollo Client
- Styled Components / Native Base (optional depending on setup)
